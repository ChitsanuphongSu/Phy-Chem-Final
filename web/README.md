# Physical Chemistry Study Hub

เว็บ React + TypeScript สำหรับทบทวน Chemical Kinetics และ Electrochemistry โดยใช้ข้อมูล local JSON และ LocalStorage ไม่ต้องมีฐานข้อมูลหรือ API ภายนอก

## Run

```powershell
pnpm install
pnpm dev
```

Build production:

```powershell
pnpm build
```

ฟีเจอร์: Dashboard, Study Notes, Formula Library, Practice Problems, Mock Exam, Flashcards และ Exam Focus พร้อม Light/Dark mode และ source links ไปยังสำเนา PDF ใน `public/sources/`.
